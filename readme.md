# RHB Ads Integration Guide

আপনার ওয়েবসাইটে **RHB Ads** যুক্ত করার সহজ নির্দেশিকা। নিচে বিভিন্ন ফরম্যাটের জন্য প্রয়োজনীয় স্ক্রিপ্ট ও নিয়ম দেওয়া হলো।

---

## ১. স্ক্রিপ্ট কোড (Script Codes)

আপনার প্রয়োজন অনুযায়ী নিচের যেকোনো একটি স্ক্রিপ্ট আপনার ওয়েবসাইটের এইচটিএমএল (HTML) ফাইলের `<head>` ট্যাগের মধ্যে অথবা `<body>` ট্যাগের শেষে বসিয়ে দিন।

### 🔹 শুধু ব্যানার (ডিফল্ট)
কোনো স্লট বা অতিরিক্ত প্যারামিটার না দিলে শুধু ব্যানার দেখাবে।
```html
<script async src="[https://code-myst.github.io/rhb-ads/rhb-ads.js](https://code-myst.github.io/rhb-ads/rhb-ads.js)" data-partner="sulaiman"></script>
